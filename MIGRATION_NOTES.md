## Phase 2 — Palette ("Instagram Sunset", light default)

**Choice.** The brief listed `PALETTE=A PALETTE=B PALETTE=C`; you then asked for
"professional, light colours, Instagram jaise". That is Palette A (*Sunset*):
light default, `#FAFAFB` page / `#FFFFFF` surface / `#14161F` ink, CTA gradient
`#C13584 → #833AB4`, accent `#515BD4`. It is expressed with the PRD v2.4
Appendix C token names (`--bg-base`, `--text-brand`, `--cta-gradient`,
`--ig-*` spectrum …); the dark theme uses the PRD Appendix C dark values with
the same brand. Design system: `design-system/instagrab/MASTER.md` (generated
with `/ui-ux-pro-max … --design-system --persist`, then re-based on this palette).

**Single source of truth.** `app/tokens.css` holds every raw colour (light in
`:root`, dark in `[data-theme="dark"]`), plus type, radius, spacing, z-index and
motion scales. Legacy names used by the ~98 tool pages (`--gold-*`, `--ink*`,
`--c-cyan-rgb` …) are now value-free aliases of the new semantic tokens.
Consumers that can't read CSS variables get them derived, never copied:

| Consumer | How it gets colours |
|---|---|
| Canvas tools (QuoteMaker, DP Ring, Winner Certificate, Media Kit, Collage, Wheel), QR code | `cssToken("--art-*")` (`lib/css-token.ts`) at draw time; export palettes are theme-independent `--art-*` tokens |
| OG image, `viewport.themeColor`, manifest | `lib/design-tokens.generated.ts` ← `npm run tokens` (stale file fails `npm test`) |
| `app/icon.svg`, `app/apple-icon.png`, `public/icons/*` (72–512 + maskable + shortcuts), `public/apple-touch-icon.png`, `public/icon-{192,512}.png` | `npm run icons` (renders from tokens with the pre-installed Chromium) |

**Raw colour literals outside `tokens.css`:** 476 → **202**, and all 202 sit in
five dead files (`Nav`, `SplashScreen.tsx/.css`, `SupportedTools`, `ResultCard`)
that Phase 3 deletes → 0. Gate: `node scripts/check-colors.mjs` (allow-list:
generated files, third-party brand logos in `PlatformIcons.tsx`).

**Contrast.** `npm test` asserts 116 text/UI pairs across both themes (text ≥
4.5:1, UI ≥ 3:1; glass composited on the worst-case backdrop; CTA gradient
sampled at 101 points — worst 5.11:1). `npm run contrast` runs
`python3 scripts/contrast_check.py "<fg>" "<bg>"` for every pair and writes
`docs/design/contrast-report.md` — **116 / 116 PASS**.

### 3.1 Cleanup, boundaries, language, types, content policy

- **Dead components deleted** (zero imports verified with grep + `tsc`):
  `Footer`, `HistoryList`, `Nav`, `OgDownloader`, `RecentTools`, `ResultCard`,
  `SplashScreen` (+ `.css`, `splashConfig.ts`), `SupportedTools`,
  `TwitterDownloader`, `YtThumbnail` — plus three more found by the same sweep:
  `CopyButton`, `CreatorPack` (merged into `ResultPanel`, PRD A20), `SoundToggle`
  (Settings owns the toggle). `lib/retention.ts` lost its deprecated v1 history
  API. Raw colours outside `tokens.css` are now **0** (`scripts/check-colors.mjs`).
- **`app/loading.tsx`, `app/error.tsx`, `app/global-error.tsx`**: content-matched
  skeleton; friendly retry screen (`role="alert"`, focus to heading, one Retry
  action + Home link, Next `digest` as reference) — all copy via i18n keys
  `boundary.*` (English + Hindi; other 19 locales fall back to English).
  `global-error` reads language/theme straight from storage (no providers there).
- **`<html lang>`**: the pre-paint script now sets `lang` + `dir` (RTL for ar/ur/fa)
  from `ig-lang` (or the browser language) before first paint, so static pages
  carry the chosen language; `LangProvider` keeps it in sync. Language codes moved
  to `lib/locales.ts` (server-safe). `t()` gained `{param}` interpolation and a
  provider-free `translate()`.
- **Types:** 16 explicit `any` → 0 (`api/twitter` typed syndication payload,
  `UsernameTool` profile payload — which surfaced 4 real `undefined` bugs,
  `InstallAppButton` iOS `standalone`, KV reply, extractor legacy callbacks +
  options). One documented `type Any = any` remains *inside*
  `lib/instagram-extractor.ts` for walking Instagram JSON — PRD §25.4 freezes the
  extractor internals; nothing typed `any` crosses the module boundary.
- **Images:** every `<img>` has `alt`; content images (stories, grid tiles) now
  have descriptive alt, decorative ones next to visible text keep `alt=""`.
- **Titles:** 131 of 135 pages rendered "… | InstaGrab · InstaGrab"; the page
  strings no longer repeat the brand (template adds it once). Legal pages gained
  `description` + canonical (they had neither on `main`).
- **Heavy libs:** `jszip`, `@breezystack/lamejs`, `gifenc`, `qrcode` were already
  `await import()`-ed inside the click handlers that need them — verified none is
  in any route's first-load JS (bundle table in Phase 4).
- **Content policy scan (PRD §1.4 / AC-44):** removed
  - Settings copy promising "stories/posts from accounts you follow and bypasses
    rate-limits" → PRD v2.2 copy ("…public content. Never works for private
    accounts.");
  - "Spy mode: track anyone" (follower-tracker), "accounts you follow" (ghost-feed),
    registry "secretly … seen list" + keywords `stalk`, `secret`.
  - **Added a server-side private-account guard** (AC-45): posts/reels whose owner
    is private, stories, highlights, highlight items and profile feeds now throw
    `PRIVATE` even when a Session ID could see them. Profile pictures stay
    downloadable (Instagram shows them publicly). No feature, route or copy that
    targets protected/private content remains.
- **`/api/diag`** (Flag C): owner-only in production (admin cookie); open in
  preview/dev.

### 3.2 App shell, storage hardening, haptics (PRD §4–6, §14.7, §15, §3.5–3.6)

- **Navigation:** one `ShellNav` renders the bottom **Glass Island** (≤ 1023 px)
  and the left **Glass Rail** (≥ 1024 px; 88 px, 232 px ≥ 1440 px) from the same
  4 items; the visible one is chosen by CSS only (no hydration mismatch, CLS 0 on
  resize, only one focusable landmark — AC-65). Active state is one sliding pill
  (`transform`, 350 ms `--ease-glass`, M5) with a 24×3 / 3×24 indicator. Rail has
  ArrowUp/Down roving focus. Island hides when the on-screen keyboard opens.
- **Quick Return** on `/tools` and `/history` (hide after 24 px down, show after
  12 px up) for header + island. Header is 64/72 px with a scroll hairline driven
  by an IntersectionObserver sentinel (M11). Back Bar 56 px, 48×48 Back with RTL
  mirror, `Alt+←`.
- **Keyboard:** `G` then `H/T/R/S` go-to chords (1 s window, never while typing —
  `lib/shortcuts.ts`, unit-tested), `⌘/Ctrl+K` and `/` open the Command Palette,
  whose footer now lists the shortcuts; skip-link; focus moves to the new page's
  `<h1>` after navigation; `scroll-padding` keeps focus clear of sticky bars (AC-54).
- **Glass budget:** header/back bar + island/rail = 2 blurred surfaces; solid
  fallback for `prefers-reduced-transparency`, `forced-colors`, no
  `backdrop-filter`, or Settings → Solid surfaces (`html[data-surface]`, set before
  paint; defaults ON when `deviceMemory ≤ 2`). The palette scrim lost its blur.
- **Motion budget:** the old full-page `ambient-glow` (4 infinite animations) and
  grain layer were removed; `AuroraBackdrop` (Home + Tools only) is a single
  drifting layer of three pre-rendered glows, paused when hidden, off-screen,
  reduced-motion, Data Saver, low memory, Solid surfaces or Ambient glow OFF.
  CSS route transition (M4 fallback) on page content only — chrome never fades.
- **New primitives:** `BottomSheet` (`<dialog>`: phone sheet / ≥ 600 px modal,
  swipe-down > 80 px, 48 px Close, Esc, scrim, focus return — AC-75), `Toaster`
  (M12, Undo 6 s), `OfflinePill` (info tone, auto-dismiss 3 s after reconnect).
- **Storage (`lib/storage.ts`, PRD §15.5):** Zod `.strict()` validation on every
  read (corrupt JSON → empty list, bad records dropped), v1 records upgraded with a
  canonical `platform:kind:id` key (tracking params never duplicate), Web Locks
  writes + `BroadcastChannel("ig-storage")` + `storage` event sync, quota →
  drop-oldest retry → silent memory fallback, https/CDN-only thumbnails, strict
  read-once handoff (`HandoffSchema`, 60 s TTL, 5 s skew), batch prefill,
  offline queue, Session ID in `sessionStorage` unless "Remember" (D17), MGF-1
  correction counter (no URLs). **Bug fixed while testing:** the old memory
  fallback could resurrect history that another tab had cleared.
- **Haptics (`lib/feedback.ts`):** PRD pattern table (Selection…Error), OFF by
  default under reduced motion unless the user turned it on; `celebrate()` = M9
  (24 spectrum particles, transform/opacity only).
- **Tests:** `npm test` → 52/52 (storage 11, shortcuts 2, contrast 3, existing 36).
