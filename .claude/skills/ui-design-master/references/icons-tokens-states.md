# Icons, Tokens aur Component States

Capability: `icons-tokens`. Poore token, component aur Tailwind ke dastaavez `references/design-system/` mein hain; stack shadcn ya Tailwind ho to wahin se mapping lo.

- Icons aur visual cheezein: emoji structural icon nahi (font par nirbhar, token se control nahi); vector-only (SVG ya platform vector), PNG icon nahi; semantics use se tay hoti hai (ek hi glyph kahin decorative, kahin meaningful, kahin control); press state layout ki sheema nahi badalta (rang, opacity ya elevation se); official brand logo hi, andaaze se path, unofficial recolor ya proportion badalna nahi; icon size tokens (jaise icon-sm, icon-md 24, icon-lg), 20 ya 28 jaise bikhre maan nahi; ek hi layer mein ek stroke motai (jaise 1.5 ya 2px); ek star par ek hi style (filled ya outline); tap ki jagah iOS par 44pt, Android par 48dp (hum 48), icon chhota ho to hit area badhao; icon text ki baseline se mile aur padding ek jaisi; meaningful icon aur control ki seema ka contrast kam se kam 3:1, decorative icon koi jaankari na le.
- Light aur Dark mode: surface background se saaf alag (poori transparent nahi); body text dono mein 4.5:1; border aur divider dono theme mein dikhein; pressed, focused, disabled states dono mein barabar alag dikhein; semantic tokens har theme ke liye alag value; scrim ko asli composed background par naapo.
- Layout aur spacing (app): safe area ka maan (header, tab bar, CTA bar); system bar aur gesture indicator ke liye jagah; phone aur tablet ke liye content ki chaudai tay; 4 ya 8dp rhythm; tablet par lambi text poori chaudai nahi; bade width aur landscape par kinaron ka padding badhe; tiki bar ke neeche content ko inset mile taaki chhupe nahi.
- Token ka 3 star: Primitive (kachche maan, jaise blue-600, space-4) se Semantic (matlab wale naam, jaise primary, background) se Component (jaise button-bg). Theme badalna semantic star par hota hai; component sirf semantic ya primitive ko pakadta hai. Components mein raw hex nahi.
- Component states ki priority (jab kai lagu hon): disabled, loading, active, focus, hover, default. Focus ring 2px, offset 2px, ring ka rang primary, offset ka rang background. Disabled: opacity 0.38 se 0.5, cursor not-allowed, semantic disabled. Badlaav ke ms: rang aur background 150ms ease-in-out, transform 200ms ease-out, shadow 200ms ease-out.
- Component spec ka dhancha (har component ke liye likho): Property, Default, Hover, Active, Disabled, Loading, Focus ki ek table; button variant (default, secondary, outline, ghost, link, destructive); size (sm 32, default 40, lg 48px unchai; mobile par mukhya button hamesha 48dp ya zyada, hamara tap niyam in size se upar hai); input ki halat (default, hover, focus, error, disabled); card ke variant (default, elevated, outline, interactive).
- Skill ke references/design-system/ mein poore token, component aur Tailwind integration ke dastaavez hain; stack shadcn ya Tailwind ho to wahin se mapping lo.
