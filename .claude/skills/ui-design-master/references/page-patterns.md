# Page Patterns (landing aur marketing page ke dhaanche)

Capability: `page-patterns`.

Marketing, landing ya sign-up jaise page ke liye section order aur CTA ki jagah yahan se lo. Koi bhi countdown ya "sirf kuch bache" asli hona chahiye (SURAKSHA KI ZAMEEN).

- Hero + Features + CTA: Hero, value prop, 3 se 5 feature, CTA, footer; CTA hero mein tiki aur neeche. Hero + Testimonials + CTA: Hero, problem, solution, testimonials (asli, namoona nahi), CTA.
- Product Demo + Features: Hero, video ya mockup beech mein, har section mein feature, tulna; CTA video ke paas. Minimal Single Column: Hero headline, chhota vivaran, adhiktam 3 fayde, CTA, footer; bada CTA beech mein.
- Funnel (3-step): problem, solution, action, har step par mini-CTA aur aakhir mein mukhya CTA. Comparison Table + CTA: problem, tulna table, pricing, CTA table ke neeche.
- Lead Magnet + Form: fayde wala headline, magnet ka preview, form; form ka bhejne wala button hi CTA (label kriya wala, "Submit" nahi). Pricing page: pricing headline, price cards, feature table, FAQ; har card par CTA aur nav mein tiki CTA.
- Waitlist ya Coming Soon: hero, teaser, email form, social proof; form fold ke upar. Marketplace ya Directory: search wala hero, categories, featured listing, trust aur safety; search bar hero mein.
- Trust and Authority (Enterprise Gateway): mission ya credibility, proof (logo, certificate, ank), solution, saaf CTA raasta; Contact Sales mukhya aur Login doosra; logo carousel ho to pause ya stop ho aur focus, hover, reduced-motion par ruke.
- App Store style: device mockup wala hero, screenshots, icon ke saath feature, reviews, download button. FAQ ya Documentation: search wala hero, popular categories, FAQ accordion, sampark CTA. Bento Grid: hero, bento grid mein mukhya feature, detail card, tech spec, CTA. Event ya Conference: tareekh aur jagah, speakers, agenda, sponsors, register CTA tiki. Portfolio Grid: naam aur role, project grid, about, sampark.
